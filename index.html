📖 Documentation

Complete guide to using Midwest Weather

🌟 What is Midwest Weather?

Midwest Weather is a comprehensive weather intelligence platform providing real-time weather data, forecasts, and severe weather alerts for the United States, Canada, and Australia. Built from scratch with a focus on accuracy, speed, and ease of use.

🗺️ Coverage Areas

🇺🇸 United States

  • 3,187+ cities
  • All 50 states
  • 5 regional divisions
  • Real-time NWS data

🇨🇦 Canada

  • 820+ municipalities
  • 13 provinces/territories
  • 5 regional divisions
  • Environment Canada data

🇦🇺 Australia

  • Major cities
  • 8 states/territories
  • 4 regional divisions
  • BOM Australia data

🌐 Using the Website

Weather Lookup

  1. Navigate to the Weather page
  2. Select your country (USA, Canada, or Australia)
  3. Choose your Region from the dropdown
  4. Select your State/Province/Territory
  5. Pick your City/Municipality
  6. View current conditions and 7-day forecast

Quick Search

Use the Quick Search bar at the top of the Weather page to instantly find any city by name or postal code.

🤖 Using the Discord Bot

Installation

  1. Visit the Bot page or click "Add to Discord"
  2. Select your server from the dropdown
  3. Authorize the requested permissions
  4. Bot is ready to use immediately

Basic Commands

  • /weather city:[name] - Get U.S. weather
  • /weather-ca municipality:[name] - Get Canadian weather
  • /weather-au city:[name] - Get Australian weather
  • /forecast city:[name] - Get 7-day forecast
  • /dashboard city:[name] - Interactive dashboard

📡 Live Radar

Access real-time Doppler radar for your region:

  1. Go to the Live Radar page
  2. Select your region from the dropdown
  3. Click "Load Radar" to view live data
  4. Use Play/Pause to control radar animation

🔔 Setting Up Alerts

Server Alerts

Configure automated alerts for your Discord server:

  1. Use command: /setup-alerts region:[USA/Canada/Australia]
  2. Select your specific regions
  3. Choose severity level (All/Severe/Extreme)
  4. Set the notification channel

Personal DM Alerts

Get alerts sent directly to your DMs:

  1. Use command: /alerts-subscribe
  2. Enter your location
  3. Select alert severity
  4. Confirm subscription

🔧 Data Sources & Accuracy

Midwest Weather aggregates data from multiple official sources:

  • United States: National Weather Service (NWS)
  • Canada: Environment and Climate Change Canada
  • Australia: Bureau of Meteorology (BOM)

Data is updated every 10 minutes for current conditions and hourly for forecasts.

Our Privacy Commitment

Midwest Weather is committed to protecting your privacy. This policy explains what data we collect and how we use it.

When you use Midwest Weather Bot, we collect:

  • Discord User ID: Used for command logging

  • Command Usage: Which commands you use and when
  • City Selections: Which cities you query for weather

Website Usage

When you visit midwestweather.online, we collect:

  • NO personal information: The website is completely anonymous
  • NO cookies: We don't use tracking cookies
  • NO IP logging: Your IP address is not stored

We use collected information to:

5. Third-Party Services

Midwest Weather integrates with:
