🔒 Privacy Policy

Our Commitment

Midwest Weather is committed to protecting your privacy. This policy explains what data we collect, how we use it, and your rights regarding your information.

Data We Collect

Weather Data Only:

  • City selections and weather queries
  • Command usage statistics (non-personally identifiable)
  • Server IDs where the bot is installed (for functionality only)

We DO NOT Collect:

  • Personal information (names, emails, addresses)
  • Discord messages or conversation content
  • User location data or IP addresses
  • Discord tokens or authentication credentials
  • Any personally identifiable information

How We Use Data

Data is used solely to:

  • Provide weather information you request
  • Improve bot performance and reliability
  • Track system usage for maintenance purposes
  • Cache weather data to reduce API calls

Data Storage

All data is stored locally in JSON files on our secure server. Weather data is cached temporarily (default: 10 minutes) to improve performance. Command logs may be retained for system maintenance but contain no personal information.

Third-Party Services

Weather data is fetched from the National Weather Service (weather.gov). We do not share any data with third parties for marketing, advertising, or any other purposes.

Discord Integration

When you add the bot to your Discord server, we only access the minimum permissions required for functionality. We do not read messages, store user data, or access any information beyond what's necessary to respond to commands.

Anonymous Access

The website allows completely anonymous weather lookup. No account creation or login is required. Discord OAuth (when implemented) will be optional and only for server dashboard management.

Your Rights

Since we don't collect personal data, there is no personal information to request, delete, or modify. If you have concerns about data handling, you may remove the bot from your server at any time.

Children's Privacy

Our Service does not knowingly collect any information from anyone, including children under 13. The Service is designed to provide weather information only.

Changes to Policy

We may update this Privacy Policy from time to time. Changes will be posted on this page with an updated revision date.

    Midwest Weather is a nationwide, Discord-linked weather intelligence system built entirely from the ground up over 3 months. It covers all 50 U.S. states with 3,241+ cities and integrates directly with a custom website dashboard that mirrors what the Discord bot provides.
