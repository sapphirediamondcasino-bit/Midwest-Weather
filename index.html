Interpreting Weather Data

Understanding the data provided:

  • Temperature: Actual air temperature measured in shade
  • Feels Like: Accounts for wind chill or heat index
  • Humidity: Percentage of moisture in the air
  • Wind Speed: Sustained winds, with gust speeds when significant
  • Visibility: How far you can see (important for travel)
  • Pressure: Atmospheric pressure (falling = storms approaching)

🔧 Troubleshooting

Bot Not Responding

  1. Check the Status page to see if systems are online
  2. Verify the bot has proper permissions in your server
  3. Try refreshing Discord (Ctrl+R on desktop)
  4. Ensure you're using slash commands (start with /)

Alerts Not Working

  1. Confirm alerts are set up with /setup-alerts
  2. Check that the bot has permission to send messages in the alert channel
  3. Verify you selected the correct region for your location
  4. DM alerts require allowing DMs from server members

Data Seems Incorrect

We source data from official government weather services. If data appears wrong:

  1. Verify you selected the correct city (some names are similar)
  2. Check if you're comparing to a different weather service's data
  3. Weather can vary significantly between nearby locations
  4. Report persistent issues through our support Discord
